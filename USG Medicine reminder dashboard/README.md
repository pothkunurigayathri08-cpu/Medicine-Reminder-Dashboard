# Medicine Reminder Dashboard (MediRemind)

A beginner-friendly full-stack web application designed for college students to manage and track daily medication schedules.

## Technology Stack
- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Backend:** Node.js, Express.js
- **Database:** Supabase PostgreSQL

## Prerequisites
- Node.js installed on your machine.
- A free Supabase account.

## Setup Instructions

### 1. Database Setup
1. Create a new project on [Supabase](https://supabase.com/).
2. Go to the **SQL Editor** in your Supabase dashboard.
3. Paste and run the SQL script located in `database/schema.sql`.
